# Shreyash's Portfolio

A personal developer portfolio built with plain HTML, CSS and JavaScript — no frameworks, no build step.

**[https://shreyash-portfolio.onrender.com](https://shreyash-portfolio.onrender.com)**

## About

This portfolio introduces me as a Web & Full Stack Developer and includes:

- **Home** — intro with a typed-text effect
- **About** — background, skills and what I bring
- **Services** — Web Development, Front-End Development, Responsive Web Design, JavaScript Development
- **Experience** — internships and programs completed
- **Projects** — Snake Game and Weather App, with live demo and source code links
- **Contact** — email, LinkedIn, GitHub, and a validated contact form

## Built With

- HTML5
- CSS3 (custom properties, Grid, Flexbox, responsive design)
- Vanilla JavaScript (form validation, mobile navigation, typed-text effect)
- [Typed.js](https://github.com/mattboldt/typed.js/) for the hero typing animation

## Running Locally

No build step is required. Either:

- Open `index.html` directly in a browser, or
- Use the VS Code **Live Server** extension for auto-reload while editing.

## Deployment

This site is deployed as a **Static Site** on [Render](https://render.com), connected directly to this GitHub repository:

- **Build Command:** *(none)*
- **Publish Directory:** `.`

Every push to the `main` branch automatically triggers a new deploy on Render.
